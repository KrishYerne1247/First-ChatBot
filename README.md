# First-ChatBot

A simple chatbot application built using the Groq API on Google Colab.  
This project demonstrates basic interaction with an existing LLM model, featuring minimal UI and straightforward code structure.  
It serves as my first chatbot experiment — focused on understanding API integration and conversational flow.

## Features
- Uses Groq API for LLM responses  
- Basic input/output interface  
- Lightweight and beginner-friendly design  

## Future Improvements
- Enhance UI  
- Add conversation memory  
- Integrate error handling for token limits
